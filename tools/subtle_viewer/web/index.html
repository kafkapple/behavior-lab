What DEK compares and how to use it

DEK (Differential Expression of Kinematics) summarizes movement features within each cluster for each animal, then compares two project groups. Open a labeled session, load the saved project with at least two groups, choose a cluster level, and press Compute DEK.

Choose vertex speed, edge length, or angle, then value (n=0), first change (n=1), or second change (n=2). Orange means the first group has a higher feature mean; blue means the second. A star uses BH-adjusted p across all tested cluster × feature cells of the selected level; it does not correct for trying multiple levels. At least two animals per group need 30 frames in that cluster. This is exploratory for the CORT folder-defined groups.
